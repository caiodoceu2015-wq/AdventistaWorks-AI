# SchoolWorks AI - Plataforma de Trabalhos Escolares

🎓 **Escola Adventista** - Plataforma tecnológica para desenvolvimento de trabalhos escolares com IA e reconhecimento facial.

## 🚀 Funcionalidades

- ✅ **Autenticação** - Login e registro para alunos e professores
- ✅ **Seleção de Ano Escolar** - 6º ao 3º EM
- ✅ **Matérias Separadas** - Organizado por disciplina
- ✅ **Editor de Imagens** - Upload com suporte a PNG transparente
- ✅ **IA Orientadora** - Assistente com OpenAI
- ✅ **Reconhecimento Facial** - Login biométrico para professores
- ✅ **Design Dark/Green** - Interface tecnológica moderna
